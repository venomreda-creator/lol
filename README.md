# LaneLab

개인 경기 기록을 바탕으로 LoL 챔피언 연습을 추천하는 웹 앱 프로토타입입니다.

## 실행

현재 버전은 Python 표준 라이브러리로 실행합니다. 프로젝트 폴더에서 서버를 시작하세요.

```bash
python server.py
```

그다음 `http://localhost:8001`을 엽니다. 서버는 `.env`의 `RIOT_API_KEY`를 읽어 Account-V1 계정 조회를 대신 호출합니다. 브라우저에서 직접 키를 사용하지 않습니다.

챔피언 이름과 이미지는 Data Dragon에서 가져오며, 네트워크에 연결되지 않으면 기본 이름으로 표시됩니다.

## 현재 데모 범위

- Riot ID, 지역, 포지션을 입력하는 분석 폼
- 지역별 Riot ID를 최대 10개까지 등록하고 예시 통계를 통합하는 기능
- Account-V1로 Riot ID의 PUUID를 서버에서 조회
- 포지션별 예시 경기 통계, 챔피언 추천, 연습 과제
- 분석 기록을 브라우저 `localStorage`에 저장·삭제
- 반응형 한국어 대시보드

**Match-V5와 AI 코칭은 아직 연동되지 않았습니다.** Account-V1 조회에 성공해도 경기 분석 수치는 데모용입니다. API 키는 `.env`에 보관하고 Git에 커밋하지 마세요.

기능 요구사항과 제품 범위는 [PRD.md](PRD.md)를 참고하세요.
